The pace curve of the Analysis screen: the fastest stretch of each length of time inside given stretches of the runs (a block's segments, a run whole), merged across runs in one pass over the run files in the Processing Worker; and the estimate fitted to it, Riegel's power law as an envelope with the predicted times and the critical speed model.
