The Analysis screen (/analysis): an items bar of chips (a block, a run, or a run set such as "Runs since 2026-03-01 · tag easy · maximum" with Save as block), "+ Add block or run" opening a picker with two tabs, Blocks and runs (searchable list) and Runs matching… (period presets or dates, workout type, shoes, title contains, the statistic of each run; the matching runs counted live; Add these runs). Metric pills, a second row of Fastest stretch pills (5 min … 10 km), Raw | Corrected, Join points, Trend line and Pace curve switches. One Over time chart per metric on a shared time axis: each block's instances and each set's runs as points in the item's colour and shape, the trend line and noise band per block and set, each run's average as one point. With Pace curve on, a Pace curve chart: for each length of time (30 s … 2 h, logarithmic) the fastest stretch of that length across the item's runs, one line per run or run set, a point's tooltip naming the run and its minutes; blocks have none. The table of changes (one row per block or set, one cell per metric: the change, its percentage, the verdict chip, the noise and the count; blocks have no stretch). The verdicts in words per block (per device series) and per set (one sentence per metric). Under them, Runs behind the answer: the runs of a set (choice of set and metric), by date or best or worst first with top N, each with Open run → (a fastest stretch selected on the run).
