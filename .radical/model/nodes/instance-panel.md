Right-side sliding panel that keeps the chart visible. Tabs "Accepted" and "Rejected": each row shows date, run, pace, metric value and, for rejected ones, the reason (e.g. "pace steadiness 0.22 > 0.15"). Selecting a row (or clicking a chart point) shows the instance's four context layers as grouped key-value cards: block, before, run, day; with "Open run" to jump to the Run screen at that fragment.
