Centered onboarding card on a calm background that follows the OS theme (light or dark). First launch: the Strideprism mark, one sentence on what it does, a primary "Choose data folder" button (showDirectoryPicker) and a note that data never leaves the computer. Later launch: the remembered folder name with a "Continue with my-folder" button that confirms access, and a quiet "Choose another folder" link. In Firefox or Safari the card shows only a not-supported message naming Chrome, Edge and Opera, with no buttons.
